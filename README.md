# 🪔 Happy Diwali - Personalized Wish Sharing Platform

A static web app to create and share personalized Diwali wishes with photos. No backend, no database: everything travels in the shareable link.

## ✨ Features

- Beautiful rangoli-themed UI with 4 color themes (maroon, saffron, emerald, indigo)
- Photo upload with preview (stored in the link, full quality)
- Gift box opening animation and rangoli that draws itself as you type
- Background Diwali music with mute toggle
- Save the wish card as a PNG image
- Share directly to WhatsApp (image attached on mobile via Web Share API)
- Mobile-friendly responsive layout
- Built by Kiran Patil

## 🚀 Deploy

Static site: no build step. Publish the project root.

### Netlify
1. New site → Import from Git → select this repo
2. Build command: (empty)
3. Publish directory: `.` (root)
4. Deploy
